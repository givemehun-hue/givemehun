# 태스크마스터 한글패치

태스크마스터의 한글패치 배포 파일을 위한 저장소입니다.

- **제작자:** 태스크마스터
- **공식 배포 블로그:** https://blog.naver.com/jsyhmju
- **파일 다운로드:** [Releases](https://github.com/givemehun-hue/givemehun/releases)

## 이용 안내

게임별 지원 기종, 적용 대상 버전, 설치 방법과 주의사항은 해당 블로그 게시물 및 릴리즈 설명을 확인해 주세요.

패치 파일은 각 릴리즈의 **Assets**에서 내려받을 수 있습니다. GitHub가 자동으로 표시하는 **Source code (zip / tar.gz)**는 패치 파일이 아닙니다.

업데이트 소식과 문의는 공식 배포 블로그를 이용해 주세요.
